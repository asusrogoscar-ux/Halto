# HALTO

Application sportive mobile-first. Première version de démarrage.

## Prérequis
- Node.js 20.9 ou supérieur
- npm

## Installation
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000.

## Déploiement Vercel
Importer le dépôt GitHub dans Vercel. Le framework Next.js doit être détecté automatiquement.
